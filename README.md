
# Dream Finance – Financial Performance Analytics

## Project Overview
This project focuses on analyzing financial performance using Tableau Desktop. It examines revenue, income, expenses, investment returns, and profit to understand the organization's financial performance from 2023 to 2025.

## Project Objectives
- Analyze overall financial performance.
- Understand revenue and income trends.
- Evaluate expenses and investment returns.
- Monitor profitability.
- Present financial insights through an interactive Tableau dashboard.

## Tools & Technologies
- Tableau Desktop
- Microsoft Excel
- Data Visualization
- KPI Reporting

## Dataset Information
- Dataset: Dream_Finance_Simple_Dataset.xlsx
- Total Records: 600
- Total Columns: 11
- Date Range: 2023–2025

## Key Performance Indicators (KPIs)

| KPI | Result |
|---|---:|
| Total Revenue | ₹24.18M |
| Total Investment Return | ₹0.25M |
| Total Expenses | ₹6.72M |
| Total Income | ₹12.22M |
| Total Profit | ₹5.50M |
